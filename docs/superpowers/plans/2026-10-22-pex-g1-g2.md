# PEX Weeks 1–2 (through G1 and G2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** By Nov 3, have a reproducible Hardcaml → GDS flow on CMOS5L, a measured memory decision (G1), and a frozen ISA backed by firmware that passes on the reference model (G2), plus the first draft of the experiment format.

**Architecture:**

- One dune project. Hardcaml RTL lives in `hw/` and is emitted as `src/project.v` for the Tiny Tapeout template.
- A single OCaml ISA library (`hw/isa`) is shared by the assembler (`tools/asm`), later by the RTL core, and by a generated `spec/isa.json` that Codex's Python model reads.
- Firmware (`fw/`) is tested in Python against Codex's model through a thin adapter, with peers written by us.

**Tech Stack:**

- OCaml 5 + dune, `hardcaml`, `hardcaml_waveterm`, `ppx_hardcaml`, `ppx_expect`, `ppx_yojson_conv`
- Tiny Tapeout `ttihp-verilog-template@cmos5l`, LibreLane via GitHub Actions
- OSS CAD Suite (Icarus Verilog, Verilator, Yosys, SymbiYosys)
- Python 3.11+ venv with `cocotb` and `pytest`

**Spec:** `docs/superpowers/specs/2026-10-21-pex-design.md` (rev 2). Read §3–§8 and §10a before any task.

## Review Focus

1. **Out-of-range assembler operands** (`at +2048`, `ldi r0, 256`, `outb 8`, a label beyond word 255) must be a line-numbered error, never silent truncation. Tests: Task 5, `test_range_errors`.
2. **Stale generated files.** `src/project.v` or `spec/isa.json` out of sync with the OCaml source passes locally and breaks CI or the model. Tests: Task 2, `gen_is_fresh`; Task 4, `isa_json_is_fresh`.
3. **Outputs driven during reset.** `uio_oe` must be 0 while `rst_n` is low (spec §4.5). Test: Task 2, `test_reset_releases_uio`.
4. **Non-canonical instruction words** (reserved bits set) must decode to ILLEGAL, never alias to a valid instruction. Test: Task 4, exhaustive 65,536-word round trip.
5. **Experiment JSON boundary values** (param 0xFFFF, experiment ID 0xFFFF, an unknown field, a missing field) must round-trip or be rejected explicitly. Test: Task 11, `experiment_roundtrip_edges`.

  ```ocaml
  type reg = R0 | R1 | R2 | R3
  type field = Out | Oe | Mask
  type alu = Mov | Add | Sub | And | Or | Xor | Cmp | Shl | Shr
  type cond = Always | Z | Nz | C | Nc | Call | To | Nto
  type edge = Disarm | Rise | Fall | Either | High | Low
  type half = Lo | Hi
  type t =
    | Ldi of reg * int | Cmpi of reg * int | Alu of alu * reg * reg
    | Jump of cond * int | Djnz of reg * int
    | Stg_imm of field * int | Stg_reg of field * reg
    | Outb of int | Outl of int | Inb of int | Inr of int
    | Ldsr of reg | Stsr of reg | Ssl | Ssr
    | At_imm of { sample : bool; offset : int } | At_param of { sample : bool; p : int }
    | Wait | Wait_imm of int | Wait_param of int | Sync | Arm of int * edge
    | Ret | Halt | Fault of int | Push of reg | Pull of reg
    | Ldp of reg * int * half | Mark of int
  val encode : t -> (int, string) result   (* Error on out-of-range operand *)
  val decode : int -> t option             (* None = ILLEGAL *)
  val to_string : t -> string              (* assembler syntax, Task 5 *)
  val spec_json : unit -> Yojson.Safe.t
  val spec_markdown : unit -> string
  ```

**Encoding v0** (16-bit word, `op = w[15:12]`; **every bit not named below must be 0, else ILLEGAL**):

| op | Mnemonic | Fields |
|---|---|---|
| 0x0 | `ldi r, imm8` | r[11:10], imm[7:0] |
| 0x1 | `cmpi r, imm8` | r[11:10], imm[7:0] |
| 0x2 | ALU `rd, rs` | alu[11:8] (0 mov, 1 add, 2 sub, 3 and, 4 or, 5 xor, 6 cmp, 7 shl, 8 shr), rd[7:6], rs[5:4] (rs = 0 for shl/shr) |
| 0x3 | jump `addr` | cond[10:8] (0 jmp, 1 jz, 2 jnz, 3 jc, 4 jnc, 5 call, 6 jto, 7 jnto), addr[7:0] |
| 0x4 | `djnz r, addr` | r[11:10], addr[7:0] (decrement r; jump if ≠ 0; flags unchanged) |
| 0x5 | `stg field, imm8` | field[11:10] (0 out, 1 oe, 2 mask), imm[7:0] |
| 0x6 | SR/pin | sub[11:8]: 0–2 `stg field, r` (r[7:6]); 3 `outb j`; 4 `outl j`; 5 `inb j`; 6 `inr j` (j[2:0]); 7 `ldsr r`; 8 `stsr r` (r[7:6]); 9 `ssl`; 10 `ssr` |
| 0x7 | `at +n[, sample]` | sample[11], n[10:0] (0..2047) |
| 0x8 | `wait +t` | t[11:0] (0..4095) |
| 0x9 | system | sub[11:8]: 0 `at pN[, sample]` (sample[4], N[1:0]); 1 `wait`; 2 `wait pN` (N[1:0]); 3 `sync`; 4 `arm j, edge` (j[6:4], edge[2:0]: 0 disarm, 1 rise, 2 fall, 3 either, 4 high, 5 low); 5 `ret`; 6 `halt`; 7 `fault c` (c[3:0]); 8 `push r`; 9 `pull r` (r[7:6]); 10 `ldp r, pN.lo/hi` (r[7:6], hi[4], N[1:0]) |
| 0xA | `mark imm8` | imm[7:0] |
| 0xB–0xF | — | ILLEGAL |

SR semantics (spec §8):
- `outb j`: staged out[j] ← SR[7], no shift.
- `outl j`: staged out[j] ← SR[0], no shift.
- `inb j`: SR ← (SR ≪ 1) | SAMPLE[j].
- `inr j`: SR ← (SAMPLE[j] ≪ 7) | (SR ≫ 1).
- `ssl` / `ssr`: shift with a zero fill.

ALU semantics:
- `shl`: C ← r[7], r ← r ≪ 1.
- `shr`: C ← r[0], r ← r ≫ 1.
- `cmp`/`cmpi`: set Z and C as for `sub`, without writing.
